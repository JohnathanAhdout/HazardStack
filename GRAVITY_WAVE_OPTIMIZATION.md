# Atmospheric Gravity Wave Optimization for Rain Prediction

## 🌀 Overview

This document describes the **Atmospheric Gravity Wave Detection** optimization added to the HazardStack rain prediction model. This optimization improves rainfall forecasting by detecting atmospheric ripples that precede convective precipitation events.

## 📚 Scientific Background

### What Are Atmospheric Gravity Waves?

Atmospheric gravity waves (AGWs) are **buoyancy oscillations** in the atmosphere—NOT to be confused with gravitational waves from space-time! They are analogous to ripples on a pond, but occurring in the air.

**Physical Mechanism:**
1. Air is disturbed vertically (by mountains, convection, fronts)
2. Gravity pulls the air back down
3. Air overshoots and oscillates, creating a wave pattern
4. Waves propagate horizontally and vertically through the atmosphere

**Visible manifestations:**
- Lenticular (lens-shaped) clouds over mountains
- Wave clouds in parallel bands
- Rippled cirrus patterns

### Why Do Gravity Waves Matter for Rain Prediction?

Research has shown that atmospheric gravity waves are **critical precursors** to severe convective weather and heavy precipitation:

#### 1. **Convective Generation**
- Thunderstorms and deep convection generate strong gravity waves
- Waves carry information about storm intensity and evolution
- Wave momentum flux indicates convective vigor

#### 2. **Predictive Signatures**
- Gravity wave patterns appear **BEFORE** heavy rainfall
- Temperature and pressure oscillations precede storm development
- Wave activity flux indicates regions of upcoming convective initiation

#### 3. **Tropical Weather Systems**
- In tropics, most gravity waves are generated by moist convection
- Convectively Coupled Kelvin Waves (CCKWs) influence global rainfall patterns
- Gravity waves modulate the diurnal cycle of precipitation

#### 4. **Extreme Events**
- Strong gravity waves correlate with extreme rainfall
- Wave breaking can trigger secondary convection
- Momentum deposition affects mesoscale circulation

### Feature Extraction Pipeline

#### 1. Brunt-Väisälä Frequency (N²)

The fundamental parameter for wave propagation in the atmosphere.

**Formula:**
```
N² = (g/θ) × dθ/dz
```
Where:
- g = gravitational acceleration (9.81 m/s²)
- θ = potential temperature
- z = height

**Physical Meaning:**
- N² > 0: Stable atmosphere, waves can propagate
- N² = 0: Neutral atmosphere
- N² < 0: Unstable atmosphere, convection occurs

**Typical Range:** 1×10⁻⁵ to 1×10⁻³ s⁻²

#### 2. Temperature Perturbation Detection

Extracts wave signatures from temperature time series.

**Steps:**
1. Detrend temperature series (remove linear trend)
2. Compute RMS amplitude: `T_amp = √⟨T'²⟩`
3. Calculate variance: `σ²_T = Var(T')`
4. Find dominant period using autocorrelation
5. Normalize wave energy: `E_wave = σ²_T / ⟨T⟩`

**Typical Values:**
- Amplitude: 0.5-5 K for significant gravity waves
- Period: 10-120 minutes
- Energy: 0.001-0.02 (normalized)

#### 3. Pressure Perturbation Detection

Similar to temperature, but for atmospheric pressure.

**Steps:**
1. Detrend pressure series
2. Compute RMS amplitude: `P_amp = √⟨P'²⟩`
3. Calculate tendency: `∂P/∂t` (hPa/hour)
4. Measure oscillation strength (high-frequency variance)

**Typical Values:**
- Amplitude: 0.5-3 hPa for mesoscale gravity waves
- Tendency: ±5 hPa/hour during storm passage
- Oscillation: 0.2-1.0 hPa for active waves

#### 4. Momentum Flux

Represents the vertical transport of horizontal momentum by waves.

**Formula:**
```
F_momentum = √(⟨u'w'⟩² + ⟨v'w'⟩²)
```
Where:
- u' = zonal wind perturbation
- v' = meridional wind perturbation
- w' = vertical wind perturbation

**Physical Meaning:**
- Measures wave-mean flow interaction
- Critical for atmospheric circulation
- Large values indicate strong wave activity

**Typical Range:** 0.01-10 m²/s² (larger for strong convection)

#### 5. Convective Source Term

Estimates gravity wave generation from convection.

**Formula:**
```
S_convective = (R/50) × (CAPE/3000) × (H_cloud/15000)
```
Where:
- R = precipitation rate (mm/h)
- CAPE = Convective Available Potential Energy (J/kg)
- H_cloud = cloud top height (m)

**Physical Basis:**
- Higher precipitation → stronger convective heating
- Higher CAPE → more unstable, stronger updrafts
- Higher clouds → deeper convection, stronger waves

**Range:** 0-1 (normalized source strength)

#### 6. Wave Activity Flux

Combined metric of overall wave activity.

**Formula:**
```
A_wave = (|T'|/5 + |P'|/2 + |∇·u|/10⁻⁴) / 3
```

Normalized combination of:
- Temperature perturbations
- Pressure perturbations
- Wind divergence

**Range:** 0-1 (higher = more active waves)

## 💻 Code Usage

### Basic Usage

```python
from hazard.features.rain_features import RainFeatureBuilder
from hazard.features.gravity_wave_detector import GravityWaveDetector

# Initialize feature builder with gravity waves enabled
feature_builder = RainFeatureBuilder(
    climatology_data=None,
    api_decay=0.85,
    enable_gravity_waves=True  # Enable GW optimization
)

# Build features for a cell
features = feature_builder.build_features(
    current_rainfall={'cell_123': 15.5},  # mm/h
    historical_rainfall=rain_df,
    timestamp=datetime.now(),
    h3_cell='cell_123',
    meteorological_data={  # Optional: provide real weather data
        'temperature': 298.15,  # K
        'pressure': 1008.5,  # hPa
        'temperature_history': temp_array,
        'pressure_history': pres_array,
        'timestamp_history': time_array,
        'cape': 1500,  # J/kg
        'cloud_top': 12000,  # m
        # Wind data (optional)
        'u_wind': u_wind_array,
        'v_wind': v_wind_array,
        'w_wind': w_wind_array
    }
)

# Features now include 32 dimensions: 21 traditional + 11 gravity wave
print(f"Feature vector shape: {features.shape}")  # (32,)
print(f"Feature names: {feature_builder.get_feature_names()}")
```

### Standalone Gravity Wave Detection

```python
from hazard.features.gravity_wave_detector import GravityWaveDetector
import numpy as np

# Initialize detector
detector = GravityWaveDetector(
    reference_pressure=1013.25,  # hPa
    reference_temp=288.15,  # K (15°C)
    wave_period_range=(10, 120),  # minutes
    wavelength_range=(10, 1000)  # km
)

# Example: Detect gravity waves from weather station data
temperature_series = np.array([295.2, 295.8, 296.1, 295.6, 295.0, ...])  # K
pressure_series = np.array([1012.5, 1013.2, 1012.8, 1011.9, 1012.1, ...])  # hPa
timestamps = np.array([...])  # Unix timestamps

# Extract all 11 gravity wave features
gw_features = detector.extract_features(
    temperature=temperature_series[-1],
    pressure=pressure_series[-1],
    temperature_history=temperature_series,
    pressure_history=pressure_series,
    timestamp_history=timestamps,
    precipitation_rate=12.5,  # mm/h
    cape=1800,  # J/kg
    cloud_top=11000  # m
)

print(gw_features)
# {
#   'gw_buoyancy_frequency': 0.0112,
#   'gw_temp_amplitude': 1.85,
#   'gw_temp_variance': 3.42,
#   'gw_dominant_period': 45.2,
#   ...
# }
```
