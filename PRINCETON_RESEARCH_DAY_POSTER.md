## DESIGN PRINCIPLES

### Typography Hierarchy:
1. **Main Title:** 120pt, Bold, Princeton Orange
2. **Section Titles:** 48pt, Bold, Dark Blue
3. **Body Text:** 32pt, Regular, Black
4. **Captions:** 28pt, Italic, Gray
5. **Statistics:** 72pt, Bold, Color-coded

### Visual Elements:
- Use **rounded rectangles** for stat boxes (0.5" radius)
- Include **icons/emojis** for visual interest (but sparingly)
- Add **subtle drop shadows** (3px, 10% opacity)
- Use **white space** generously (1-2" margins)

### Image Suggestions:
1. **Atmospheric waves:** Lenticular clouds or wave clouds
2. **AI/Technology:** Neural network diagram or abstract tech graphic
3. **Impact:** Happy people using phones, or community gathering
4. **Maps:** India map with highlighted risk zones

## POWERPOINT CREATION INSTRUCTIONS

### Step 1: Set Up Dimensions
1. Open PowerPoint
2. Design → Slide Size → Custom Slide Size
3. Width: 40 inches
4. Height: 30 inches
5. Click OK

### Step 2: Set Background
1. Design → Format Background
2. Solid Fill → White or #F5F5F5
3. Apply to All

### Step 3: Create Layout Grid
1. Insert → Shapes → Rectangle
2. Create three columns:
   - Left: 0" to 12" width
   - Center: 12" to 28" width
   - Right: 28" to 40" width
3. Use ruler guides (View → Ruler, View → Guides)

### Step 4: Add Content
1. Insert → Text Box for each section
2. Copy content from sections above
3. Format fonts according to typography hierarchy
4. Insert shapes for stat boxes (Insert → Shapes → Rounded Rectangle)

### Step 5: Add Images
1. Place docs/images/*.png files in center column
2. Use system_architecture.png as main centerpiece
3. Add gravity_wave_features.png in results section
4. Add performance_metrics.png in statistics area

### Step 6: Add Visual Elements
1. Insert icons from Insert → Icons or download from noun project
2. Add QR code from QR code generator websites
3. Insert Princeton logo (download from Princeton brand assets)

### Step 7: Final Touches
1. Align all elements (Home → Arrange → Align)
2. Distribute spacing evenly
3. Check all fonts are readable from 3 feet away
4. Spell check everything
5. Export as PDF (File → Export → Create PDF/XPS)

## CONTENT GUIDELINES FOR PRD

✅ **DO:**
- Use plain language (avoid jargon)
- Focus on impact and "why it matters"
- Include compelling visuals
- Make it conversational
- Show real-world applications
- Use active voice

❌ **DON'T:**
- Include technical formulas (unless absolutely necessary)
- Use acronyms without explanation
- Overcrowd with text
- Use dark backgrounds
- Include too many details
- Make it look like a journal article

## PRINTING SPECIFICATIONS

**For Princeton Research Day:**
- Format: PDF (high resolution, 300 DPI minimum)
- Color space: RGB (for digital display) or CMYK (for print)
- Bleed: Add 0.25" bleed on all sides if printing physically
- Fonts: Embed all fonts in PDF
- File size: Keep under 50 MB for easy sharing

**Export Settings in PowerPoint:**
1. File → Export → Create PDF/XPS
2. Options → Optimize for: Standard (publishing online and printing)
3. Check "ISO 19005-1 compliant (PDF/A)"
4. Click OK → Publish
